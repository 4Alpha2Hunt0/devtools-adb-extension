# 🧠 Obsidian Brain

Single vault for notes, projects, and tools. Use the commands below (via the
**Obsidian Brain** plugin) instead of creating files by hand — they keep
frontmatter, links, and the tool log consistent.

## Quick commands
- `Obsidian Brain: Log tool usage` — record that you used a tool right now.
  Creates/updates the tool's note and appends a linked entry to today's daily note.
- `Obsidian Brain: New tool reference note` — catalog a tool without logging a use.
- `Obsidian Brain: New project note` — start a new project note from the template.
- `Obsidian Brain: Refresh tools dashboard` — rebuild [[Tools/Dashboard]] from
  every note in `Tools/`, sorted by how often each tool has been used.

## Map of content
- [[Tools/Dashboard|Tools Dashboard]] — every tool, usage count, last used
- `Projects/` — one note per project/repo you're tracking
- `Daily/` — auto-created daily logs (tool usage lands here too)
- `Templates/` — note templates used by the plugin
